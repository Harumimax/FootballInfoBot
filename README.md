# FootballInfoBot

**FootballInfoBot** следит за футбольными турами и присылает короткие футбольные обновления прямо в Telegram.

Он создан для спокойного режима: подписался на лигу или команду, получил актуальную картину, а дальше бот сам пишет только в дни матчей.

## ⚽ Что Умеет

- `🏆` подписывать на Англию, Испанию, Германию, Италию, Францию и Россию;
- `⭐` подписывать на отдельную команду внутри лиги;
- `📌` показывать активные подписки кнопками;
- `📊` присылать турнирную таблицу;
- `📅` показывать текущий тур и догоняющие матчи;
- `🔔` отправлять утренние и итоговые уведомления в дни игр;
- `🥅` показывать голы в матчах, когда источник даёт детали.

## 🚀 Как Пользоваться

1. Откройте бота в Telegram.
2. Нажмите `/start`.
3. Выберите `Подписаться на Лигу, турнир или команду`.
4. Выберите подписку на лигу/турнир или на команду.
5. Отметьте нужные варианты кнопками.

Если подписаться на лигу, бот сразу пришлёт состояние текущего тура. Если подписаться на команду, бот будет писать в дни матчей этой команды.

## 🏆 Лиги

Сейчас доступны:

- `🇬🇧 Англия`
- `🇪🇸 Испания`
- `🇩🇪 Германия`
- `🇮🇹 Италия`
- `🇫🇷 Франция`
- `🇷🇺 Россия`

Следующими можно добавить еврокубки и другие турниры.

## ⭐ Подписки На Команды

Командный сценарий простой:

1. Нажать `Подписаться на команду`.
2. Выбрать лигу.
3. Выбрать команду из списка.

Список команд берётся из данных лиги и показывается по алфавиту. Активная подписка отмечается галочкой.

## 🎛️ Меню Бота

- `📌 Мои подписки` - показывает подписки кнопками с галочкой. Нажатие на кнопку отписывает.
- `➕ Подписаться на Лигу, турнир или команду` - открывает выбор типа подписки.
- `📊 Турнирная таблица` - показывает таблицу выбранной лиги.
- `📅 Текущий тур` - показывает актуальный тур и догоняющие матчи.
- `ℹ️ Помощь` - объясняет источник данных и базовую логику бота.

## 🧾 Формат Сообщений

Бот пишет компактно: дата, время, команды и счёт.

```text
🇪🇸 Испания

📅 Матчи сегодня
28.08 20:00 Расинг 1:2 Эльче
  ⚽ 03 Роналду
  ⚽ 25 Месси
  ⚽ 88 Месси

🏆 3-й тур
28.08 20:00 Расинг 1:2 Эльче
28.08 22:30 Алавес 0:0 Вильярреал
29.08 18:00 Леванте - Бетис

↩️ 1-й тур
27.08 22:00 Барселона 2:0 Атлетик
```

Если матч ещё не сыгран, счёта нет:

```text
29.08 20:00 Реал Сосьедад - Эспаньол
```

## 🔔 Уведомления

Бот пишет только в дни матчей.

- `09:00 Europe/Moscow` - утреннее состояние тура или матча команды.
- После матчей дня - итоговое состояние с результатами.
- Если матчи ещё идут поздно вечером, бот проверяет их каждый час до `03:00`.

Если пользователь подписан на несколько лиг, сообщения приходят отдельно по каждой лиге. Если подписка только на команду, сообщение будет про матчи этой команды.

## 🧭 Если Данных Нет

Иногда источник ещё не обновился или на странице нет нужной информации. В этом случае бот отвечает честно:

```text
⏳ Данных пока нет
```

## 🌐 Источник Данных

Данные берутся с сайта [football.kulichki.net](https://football.kulichki.net/).

FootballInfoBot не является официальным сервисом football.kulichki.net и не связан с владельцами сайта. Бот обрабатывает публично доступную информацию и показывает её пользователю в удобном формате.

## 💚 Идея Проекта

Футбол часто шумный: туры, переносы, догоняющие матчи, поздние результаты.

FootballInfoBot должен быть спокойным помощником. Когда матчей нет, он молчит. Когда есть игра, он приносит ровно то, что нужно знать.
